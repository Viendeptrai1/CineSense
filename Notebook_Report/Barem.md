II. BAREM CHI TIẾT (10 ĐIỂM)

1. Mức độ hoàn thiện đề tài - 1.5 điểm


| Nội dung                   | Mô tả                                                                                       | Điểm |
| -------------------------- | ------------------------------------------------------------------------------------------- | ---- |
| Xác định đúng bài toán NLP | Bài toán rõ ràng, xác định đúng loại task (classification, QA, summarization, retrieval...) | 0.5  |
| Phân tích yêu cầu          | Trình bày mục tiêu hệ thống, input - output, phạm vi giải quyết                             | 0.5  |
| Thu thập & mô tả dữ liệu   | Nguồn dữ liệu rõ ràng, mô tả đặc điểm văn bản (ngôn ngữ, số mẫu lớp)                        | 0.5  |


1. Cơ sở lý thuyết - 1.0 điểm


| Nội dung                        | Yêu cầu                                                                      | Điểm |
| ------------------------------- | ---------------------------------------------------------------------------- | ---- |
| Kiến thức NLP cơ bản            | Trình bày các khái niệm nền tảng: tokenization, embedding, language model... | 0.5  |
| Thuật toán chính/ mô hình chính | Giải thích đúng mô hình sử dụng (Naive Bayes, LSTM, Transformer, BERT...)    | 0.5  |


1. Tiền xử lý dữ liệu - 1.5 điểm


| Nội dung          | Mô tả                                                                  | Điểm |
| ----------------- | ---------------------------------------------------------------------- | ---- |
| Làm sạch dữ liệu  | Lowercase, remove URL/punctuation, xử lý emoji/ký tự đặc biệt          | 0.5  |
| Xử lý ngôn ngữ    | Tokenization, stopword removal, stemming/word segmentation,...         | 0.5  |
| Trực quan dữ liệu | Thống kê độ dài câu, phân bố lớp, word frequency hoặc biểu đồ minh họa | 0.5  |


1. Xây dựng mô hình - 2.5 điểm


| Nội dung                     | Yêu cầu                                                                 | Điểm |
| ---------------------------- | ----------------------------------------------------------------------- | ---- |
| Lựa chọn mô hình phù hợp     | Baseline ML hoặc Deep Learning phù hợp bài toán                         | 0.5  |
| Huấn luyện mô hình           | Chia train/test, tuning, loss, optimizer hợp lý                         | 1.0  |
| Xây dựng pipeline hoàn chỉnh | Quy trình rõ: text -> preprocessing -> vectorization -> model -> output | 0.5  |
| Tối ưu/so sánh               | So sánh các phương pháp, tăng độ chính xác                              | 0.5  |


1. Đánh giá & thực nghiệm - 1.5 điểm


| Nội dung                   | Yêu cầu                                                         | Điểm |
| -------------------------- | --------------------------------------------------------------- | ---- |
| Chỉ số đánh giá định lượng | Metric phù hợp task (Accuracy, F1, BLEU, ROUGE, Precision@k...) | 0.5  |
| Minh họa trực quan         | Confusion matrix, bảng so sánh model, ví dụ dự đoán             | 0.5  |
| Thảo luận kết quả          | Phân tích ý nghĩa, hạn chế, hướng cải thiện                     | 0.5  |


1. Ứng dụng demo - 1.0 điểm


| Hạng mục                 | Yêu cầu                             | Điểm |
| ------------------------ | ----------------------------------- | ---- |
| Demo chạy được           | Web/desktop/mobile                  | 0.5  |
| Giao diện và trải nghiệm | Input,Output,UI rõ ràng, dễ dùng    | 0.25 |
| Tính hữu ích thực tế     | Có kích bản sử dụng cụ thể (cơ bản) | 0.25 |


1. Báo cáo & bảo vệ - 1.0 điểm


| Nội dung                      | Yêu cầu                                                                    | Điểm |
| ----------------------------- | -------------------------------------------------------------------------- | ---- |
| Báo cáo đúng chuẩn            | Có giới thiệu, phương pháp, thực nghiệm, hình/bảng, tài liệu tham khảo     | 0.5  |
| Thuyết trình, trả lời câu hỏi | Trình bày rõ ràng, hiểu hệ thống, trả lời đúng chuyên môn, không đọc slide | 0.5  |
